# Imagens dos planetas

Esferas geradas a partir das texturas de Solar System Scope
(https://www.solarsystemscope.com/textures/), licença CC BY 4.0,
feitas a partir de dados e imagens de missões da NASA.

Três níveis de detalhe por planeta (128, 512 e 2048 px); o mapa troca
para a imagem maior à medida que a pessoa se aproxima.
