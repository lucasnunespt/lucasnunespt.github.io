# NeuroMedit

Meditação guiada com base em neurociência. A promessa da marca é **reduzir o ruído mental**, e cada decisão visual existe para a cumprir: nada compete, nada grita, o espaço vazio trabalha.

Os valores partiram do código do site (`lucasnunespt/NeuroMedit`, commit `474085f`). Desde outubro de 2026 a direção inverteu-se: **este sistema é a referência e o site segue-o**. O que ainda é proposta está marcado como tal e vive no Roadmap.

## Princípios

- **Uma só ação óbvia por ecrã.** Um botão principal em `accent`; tudo o resto é secundário (`line` como borda, fundo transparente) ou link em `text-soft`.
- **Tudo o que se toca vive em baixo, na zona do polegar.** O topo é para conteúdo, não para controlos. A navegação no telemóvel é uma barra inferior com no máximo três destinos.
- **A calma é demonstrada, não instruída.** As animações seguem a respiração; o texto acompanha em vez de mandar.
- **A ciência apoia a experiência, não compete com ela.** Primeiro o mecanismo no cérebro, depois a prática.
- **O problema está nas pontas.** A entrada e o regresso de uma sessão são onde as pessoas se perdem — é onde o design tem de ser mais claro.

## Como este sistema está organizado

- **Fundamentos:** Temas e cor, Tipografia e forma, Movimento e luz, Iconografia, Voz e texto.
- **Componentes:** um por cartão, cada um com guia de uso e pré-visualização viva.
- **Ativos:** Logos, Graphics e Planetas (guia em *Planetas de pontos de brilho*).
- **Como evoluir o sistema:** a regra da fonte única e o processo para adicionar algo novo.
- **Roadmap:** o que está decidido mas ainda não está no código, e o que falta cobrir.

Antes de criar qualquer tela, convite, post ou apresentação, ler *Como evoluir o sistema*.
